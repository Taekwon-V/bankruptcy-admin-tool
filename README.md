# ⚖️ 파산관제 스마트 매니저 (Bankruptcy Admin Tool)

> **법원 파산관제 업무의 디지털 혁신과 완벽한 로컬 보안을 위한 차세대 데스크톱 보조 시스템**
>
> 🔒 **100% 오프라인 로컬 처리 (Zero Leak)** | 🖥️ **좌측 50% 분할화면 최적화** | 📁 **3x3 실무형 사건 탐색기**

---

## 🏛️ 프로젝트 개요

본 프로젝트는 법원 파산관제인 및 관제보조인의 과중한 서류 검토, 금융거래 내역 분석, 보고서 작성 업무를 획기적으로 경감하기 위해 개발된 **설치형 윈도우 데스크톱 프로그램**입니다.

채무자 및 이해관계인의 민감한 금융·개인정보를 다루는 업무 특성에 맞추어 **외부 인터넷 서버 및 클라우드 전송을 100% 차단한 무설치 포터블 로컬 아키텍처**로 동작합니다.

---

## ✨ 핵심 기능 (Phase 1 완료)

### 1. 🖥️ 좌측 50% 분할화면 자동 밀착 (Split Screen Ready)
* 프로그램 실행 시 사용자 모니터 작업영역(작업표시줄 제외)을 실시간 감지하여 **화면 좌측 50% 폭에 자동으로 밀착하여 실행**됩니다.
* **우측 50% 공간에 법원 전자소송 사이트, 한글(HWP), PDF 서류를 나란히 배치**하여 원클릭 복사/붙여넣기 및 서류 대조 작업을 극대화합니다.

### 2. 🗂️ 3x3 사건 탐색기 & 3단계 드릴다운
* **연도 폴더 카드 ➔ 배정 월 폴더 카드 ➔ 3x3 사건 카드**의 직관적인 계층 구조.
* 6대 표준 실무 상태(`[신규 접수]`, `[서류 보정]`, `[통장 분석]`, `[집회·보고]`, `[환가·배당]`, `[면책·종결]`) 실시간 동적 필터링.
* **마우스 호버 시에만 부드러운 팝업 애니메이션** 및 완벽한 수평 정렬.

### 3. 📁 표준 폴더 트리 자동 생성 & 안전한 배정 이동
* 신규 사건 등록 시 `사건저장소/{연도}/{월_배정사건}/[{사건번호}] {채무자명}` 및 **4대 필수 서류 폴더** 자동 생성:
  - `01_기본서류` : 기본 인적사항, 주민등록초본, 과세증명서 등
  - `02_금융내역` : 은행/카드/보험 계좌 거래내역 엑셀 파일
  - `03_보정소명자료` : 채무자 소명서, 부동산/차량 시세 자료 등
  - `04_보고서_산출물` : 파산관제인 보고서(HWPX), 배당표(Excel)
* **파일 잠금 충돌 방지**: 서류가 한글/엑셀에서 열려 있을 경우 강제 이동을 방지하고 사용자에게 안전하게 경고 안내.

### 4. 🔍 정밀 실시간 검색 & 초성 검색 엔진
* 사건번호, 채무자명, 전화번호, 법원명 실시간 검색.
* 순수 자음 입력(`ㄱㅇㅊ`, `ㅎㄱㄷ`) 시에만 초성 검색이 발동하도록 정밀 설계되어 엉뚱한 오매칭(False Positive) 원천 방지.

### 5. 💰 직관적인 한글 금액 표기 & 전화번호 자동 포맷
* 장황한 중복 금액 표기를 배제하고 **`1억 2,345만 2,341원`** 단일 포맷으로 표기.
* 숫자 연속 입력 시에도 `010-0000-0000` 표준 하이픈 자동 포맷팅.

* **Frontend**: HTML5, Modern Vanilla CSS, ES6+ Javascript
* **Backend**: Python 3.10+, PyWebView (Edge Chromium WebView2 Native)
* **Storage**: 로컬 디스크 파일시스템 (`JSON` 메타데이터 기반 무설치 포터블)
* **Security**: 외부 서버 통신 0% (인터넷 연결 불필요)

## 🚀 빠른 시작 가이드

### 실행 방법
1. 저장소를 클론하거나 압축을 풉니다.
2. 폴더 내의 **`실행하기.bat`** 파일을 더블 클릭합니다.
   - 파이썬 가상환경 및 의존성(`pywebview`)이 없으면 자동으로 구성 후 즉시 실행됩니다.

## 🔒 보안 및 프라이버시 원칙

1. **Zero External Leak**: 어떠한 개인정보, 금융 데이터, 파일 내용도 외부 클라우드로 전송되지 않습니다.
2. **Git 추적 제외**: `.gitignore` 설정을 통해 `사건저장소/` 및 민감 파일은 깃허브 커밋 대상에서 원천 배제됩니다.
