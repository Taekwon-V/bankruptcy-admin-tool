# 안드레 카파시(Karpathy) 에이전트 행동 지침 및 로컬 보안 규칙

## 1. 생각 먼저 (Think Before Coding)
- 구현 전 가정을 밝히고 모호성을 사전에 해소합니다.

## 2. 단순성 최우선 (Simplicity First)
- YAGNI(You Aren't Gonna Need It) 원칙 준수, 과도한 추상화 및 불필요한 기능 추가 금지.

## 3. 외과의사식 정밀 수정 (Surgical Changes)
- 요청된 범위 외의 파일, 주석, 포맷을 임의로 변경하지 않습니다.

## 4. 목표 기반 자가 검증 (Goal-Driven Execution)
- 코드 작성 후 실행 및 검증 절차를 에이전트가 능동적으로 수행합니다.

## 5. 파산관제인 로컬 프라이버시 & UI 원칙
- 100% 로컬 오프라인 데이터 처리 (개인정보 외부 유출 절대 금지).
- HWPX / DOCX 한글 폰트 규격(`w:eastAsia`) 및 인코딩 철저 검증.
- 화면 절반(너비 700~960px) 분할 작업에 최적화된 반응형 UI 및 원클릭 복사/드래그앤드롭 제공.
