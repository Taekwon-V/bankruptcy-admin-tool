# Awesome Design Systems Skill

This skill provides ready-to-use design systems and token dictionaries for building distinctive, brand-grade desktop and web applications.

---

## 🍎 1. Apple macOS / HIG Design System

* **Vibe**: Clean, understated elegance, high readability, frosted glass (`backdrop-filter: blur(12px)`), neutral slate tones.
* **Palette**:
  - Background: Light `#F5F5F7` / Dark `#1E1E1E`
  - Surface: Light `#FFFFFF` / Dark `#2C2C2E`
  - Border: Light `rgba(0, 0, 0, 0.08)` / Dark `rgba(255, 255, 255, 0.1)`
  - Primary Blue Accent: `#007AFF`
  - Text Primary: Light `#1D1D1F` / Dark `#F5F5F7`
  - Text Secondary: Light `#86868B` / Dark `#A1A1A6`
* **Typography**: SF Pro / Pretendard, crisp line-height `1.5`, letter-spacing `-0.015em`.
* **Corner Radius**: `10px` (cards), `6px` (buttons), `16px` (modals).

## 📝 2. Notion Design System

* **Vibe**: Minimalist, warm/cool monochrome, distraction-free document workspace, subtle hairline borders, clear typography hierarchy.
* **Palette**:
  - Background: Light `#FFFFFF` / Dark `#191919`
  - Surface / Sidebar: Light `#F7F6F3` / Dark `#202020`
  - Hover Tint: Light `#EFEFEF` / Dark `#2C2C2C`
  - Border: Light `#E9E9E7` / Dark `#2E2E2E`
  - Text Primary: Light `#37352F` / Dark `#FFFFFF`
  - Text Secondary: Light `#787774` / Dark `#9B9B9B`
  - Text Muted: Light `#9B9A97` / Dark `#6B6B6B`
* **Corner Radius**: `4px` (subtle rounding), `6px` (popups).

## 🪟 3. Microsoft Fluent 2 / Windows 11 Design System

* **Vibe**: Professional desktop tool, familiar to court & office staff, Mica/Acrylic surfaces, clear command bars.
* **Palette**:
  - Background: Light `#F3F3F3` / Dark `#202020`
  - Surface / Card: Light `#FFFFFF` / Dark `#2B2B2B`
  - Primary Brand: `#005FB8` (Light) / `#60CDFF` (Dark)
  - Border: Light `rgba(0, 0, 0, 0.06)` / Dark `rgba(255, 255, 255, 0.08)`
  - Text Primary: Light `#1B1B1B` / Dark `#FFFFFF`
  - Text Secondary: Light `#5D5D5D` / Dark `#D1D1D1`
* **Typography**: Segoe UI Variable / Pretendard / Malgun Gothic.
* **Corner Radius**: `8px` (cards), `4px` (buttons).

## 💙 4. Toss Design System (TDS)

* **Vibe**: Ultimate Korean typography readability, high contrast, bold headlines, generous spacing, soft pastel pills.
* **Palette**:
  - Background: Light `#F2F4F6` / Dark `#101012`
  - Surface: Light `#FFFFFF` / Dark `#17171C`
  - Primary Blue: `#3182F6` (Toss Blue)
  - Text Primary: Light `#191F28` / Dark `#F9FAFB`
  - Text Secondary: Light `#4E5968` / Dark `#8B95A1`
  - Text Muted: Light `#8B95A1` / Dark `#6B7684`
* **Corner Radius**: `16px` (cards), `10px` (buttons), `24px` (modals).

## ⚡ 5. Linear Design System

* **Vibe**: Tech-forward, high-density dark mode, keyboard shortcuts (`Ctrl+K`), connected 1px hairline grids, subtle glowing indicators.
* **Palette**:
  - Background: `#0B0F17` (Obsidian)
  - Surface: `#0E1626`
  - Hairline Border: `rgba(255, 255, 255, 0.08)`
  - Accent Blue: `#3B82F6`
  - Text Primary: `#FFFFFF`
  - Text Secondary: `#CBD5E1`
* **Corner Radius**: `12px` (modals), `6px` (pills).
