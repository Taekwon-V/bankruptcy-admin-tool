# 변환 예시 (가이드라인 적용 전 → 후)

## 예시 1. 개조식 → 서술식

**(전) 개조식**
```
○ 2025년 문서작업 실태
 - 공무원 1인당 하루 76분 불필요 문서작업
 - 개선 필요
```

**(후) 서술식**
```
○ 2025년 한국행정연구원 조사에 따르면, 공무원 1인당 하루 평균 약 76분을
  불필요한 문서작업에 소모하고 있는 것으로 나타났으므로 개선이 필요함.
```

주어(조사·공무원)와 서술어(나타남·필요함)를 갖춘 완결된 문장으로 작성한다.

## 예시 2. 표 → 서술식 설명

**(전) 표**

| 시간 | 소요 | 내용 | 비고 |
|---|---|---|---|
| 14:00~14:30 | 30분 | 사례 발표 | 삼성SDS |
| 14:30~14:55 | 25분 | 작성 방법 설명 | 혁신행정담당관실 |

**(후) 서술식**
```
○ 교육은 다음 순서로 진행함.
 - 14:00부터 30분간 삼성SDS가 AI 친화적 문서혁신 사례를 발표함.
 - 14:30부터 25분간 혁신행정담당관실이 문서 작성 방법을 설명함.
```

일정표·조직도 등은 표 대신 문장으로 풀어 써야 AI가 항목 간 관계를 이해할 수 있다.

## 예시 3. 그림에 텍스트 설명 추가

**(전)** 조직도 그림만 삽입

**(후)**
```
○ 추진 체계는 다음과 같음. 참여혁신조직실이 총괄하며, 그 아래 혁신행정담당관실이
  문서 가이드라인을, 공공인공지능혁신과가 지원도구 보급을 담당함.
  <그림: 추진 체계 조직도 — 위 설명과 동일한 구조>
```

그림을 넣더라도 같은 내용을 본문에 텍스트로 반드시 서술한다.

## 완성 원고 예시 (build_hwpx.py 입력)

```
# AI 친화적 행정문서 작성 시범실시 계획(안)
> 행정안전부가 AI 시대 행정문서 작성 가이드라인을 솔선하여 적용하기 위한 시범실시 계획을 보고드림.
1. 추진 배경
○ 범정부 AI 친화적 공문서 작성을 위해 행정안전부가 문서 작성 시 가이드라인을 적용할 필요가 있음.
- 개조식 문장과 복잡한 표는 AI가 문맥을 파악하기 어려우므로 서술식으로 전환함.
2. 추진 계획
○ 가이드라인 교육을 2026년 3월 중 본부와 소속기관 직원을 대상으로 실시함.
· 대면교육과 온라인 중계를 병행하여 전 직원이 참여하도록 함.
```
